# Bundled skills

Loaded by `laps/oc/skilltool.py`. Each folder is one skill (`SKILL.md` with `name` and `description`
front matter, optional `reference/` and `scripts/`). Users can add their own in `~/.blackwall/skills/`,
`~/.agents/skills/`, or a project's `.claude/skills/`, `.agents/skills/`, `.blackwall/skills/`
(same name overrides the bundled one).

| all others | written for Blackwall (2026-10) | same as Blackwall |

guidance), rewritten in English.
