# 調べる

1. **手を動かす前に、誰かが既に踏んでいないか引く。**
   プロジェクトの障害記録・issue・過去の作業ログを症状の語で探す。数分で済む。
2. **層を分ける。** 「SSH が通らない」は「ホストが死んだ」ではない。
   網・経路・サービス・データを別々に確かめる。
3. **一次証拠を取る。** 相手が返した行をそのまま貼る。要約しない・言い換えない。
4. **仮説は 1 つずつ潰す。** 同時に 2 つ変えると、どちらが効いたか永久に分からない。
5. **分からなかったことを「分からない」と書く。** 分かった風にまとめると、
   次に同じ穴を踏む。

## 効きやすい確かめ方

    ss -lntp / ip neigh show <IP>         生きているかを TCP と ARP で
    journalctl -u <unit> --since "-30min" 時刻は**相対**で（ホストごとに時間帯が違う）
    systemctl show <unit> -p NRestarts    「自動復帰していて気づけない」を見る

⚠ `systemctl is-active` は `Restart=always` の下では**いつでも active**。生死の根拠にならない。
